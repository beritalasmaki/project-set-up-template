# Questions for the security and data protection owners

Prompts for turning gaps into questions. Adjust them to the project. Do not answer them yourself.

## Data

- Which of these items must never be shown to [role]? Which can be partly masked?
- Which items are exported or downloaded, and where do the files go?
- Is any of this data shown in notifications, emails or URLs?
- Is real data used in test or demo environments?

## Access

- Who grants and removes access? How fast must removal take effect?
- Can one person hold two roles? What happens then?
- Can a user act on behalf of another? How is that shown and recorded?

## Sign-in and sessions

- How long can a session last? What should the user see before it ends?
- What happens to a form that is half filled in when a session ends?
- How are failed sign-ins explained to the user without revealing account details?

## Consent, retention and deletion

- What does the user consent to, in which words, and where?
- How long is each kind of data kept, and who decides that?
- How does a user see, correct or delete their data? Who handles those requests?

## Audit

- Which actions must be recorded: who, what, when?
- Who may read the record, and for how long is it kept?

## AI in the product

- What data may reach a model, and where is it processed?
- What does the user need to be told, and when?
- What happens when the AI is wrong, unsure or unavailable?
- What does the client allow for AI tools in this project? (see `project.config.md`)
